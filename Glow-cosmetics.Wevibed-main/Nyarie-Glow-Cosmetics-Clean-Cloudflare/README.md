# Nikki Beauty & Cosmetics — Premium Clean Cloudflare Pages

Mobile-first React/Vite cosmetics storefront.

Confirmed business identity:
- Nikki Beauty & Cosmetics
- Category: Cosmetics / beauty products

Important: exact phone number, WhatsApp number, store location, opening hours, brands and detailed catalogue were not available in the supplied project context, so this build intentionally does NOT invent them. The contact/map area is ready for the confirmed details to be inserted.

The approved preview image is NOT used inside the website. Every section uses separate relevant cosmetics imagery. A circular floating WhatsApp button is included and currently anchors to the contact section until the real WhatsApp number is confirmed.

Deploy:
npm install
npm run build
Cloudflare Pages build command: npm run build
Output directory: dist
